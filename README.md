# 100 Days of Code: Python Development Portfolio

This repository documents my software engineering journey through Angela Yu's 100 Days of Code Python curriculum. The codebase serves as a practical record of my daily progression, demonstrating the application of core programming principles, problem-solving methodologies, and architectural patterns across 100 consecutive days of development.

## Repository Architecture

The project files are organized chronologically by development day to preserve the timeline of this journey and track technical milestones. Each subfolder represents a self-contained application or programmatic challenge completed as part of the coursework:

* **Days 01 - 14:** Core programming mechanics, syntax fundamentals, and algorithmic logic.
* **Days 15 - 39:** Object-Oriented Programming (OOP), local environment integration, file handling, and data processing.
* **Days 40 - 58:** Web development frameworks, templating engines, and front-end integration.
* **Days 59 - 100:** Advanced automation, web scraping, data science protocols, and graphical user interfaces.

## Environment and Core Technologies

* **Primary Language:** Python 3
* **Development Environment:** Visual Studio Code (VS Code)
* **Version Control:** Git / GitHub

## Implementation Standards

All projects within this repository are structured to emphasize clean code practices, including:
* Modular file structures and object-oriented design patterns.
* Explicit variable naming conventions and comprehensive code documentation.
* Integration of standard libraries and external packages to interface with system environments and web APIs.
